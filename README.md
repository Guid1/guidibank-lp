# GuidiBank

Landing page de um banco digital fictício desenvolvida para praticar desenvolvimento front-end.

## Funcionalidades

- Landing page responsiva
- Design moderno
- Seções institucionais
- Área de parceiros
- Integração com mapa
- Layout adaptável

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Projeto criado para estudos e prática de desenvolvimento web, focando em estruturação de páginas, estilização e experiência do usuário.
